# Security Policy

The Anceryx desktop client and the private Anceryx API have separate codebases and reporting scopes. This repository covers only the public client; the API, infrastructure, hosted services, and production systems remain private.

## Reporting a vulnerability

Please do not disclose vulnerability details in public issues, discussions, or pull requests. Use GitHub's private vulnerability reporting feature for this repository when it is enabled. If it is unavailable, contact the Anceryx maintainers through an established private channel and ask for the current secure reporting method. Do not send sensitive details through an unverified address or public channel.

Include a description, affected version and environment, reproduction steps, and likely impact. Redact credentials, tokens, personal information, private messages, and production data from logs and screenshots. Do not access other users' data or make changes to production accounts, services, or databases while investigating.

For issues involving the private API or hosted infrastructure, do not probe or test the production service. Use an established private channel to request the appropriate reporting route.

## Scope and response

Reports are reviewed by the maintainers. No response time, service-level commitment, or bounty is promised. The maintainers may ask for additional information and will coordinate any public disclosure where appropriate.
