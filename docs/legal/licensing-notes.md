It is not an open-source license approved by the Open Source Initiative.

This draft expresses the project owner's requested policy. Qualified legal review is still required before public release, including review of jurisdiction, enforceability, contributor terms, public GitHub fork behavior, and applicable law. This document is not legal advice.

See [third-party notices](third-party-notices.md), the [dependency inventory](third-party-license-inventory.md), and the [distribution checklist](public-distribution-checklist.md).
