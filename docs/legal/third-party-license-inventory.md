# Third-party license inventory

The active dependency inventory is generated from `package-lock.json` during the Electron build and shown in Settings > About > Open-source licenses. Run `npm run audit:licenses` to inspect the committed lockfile. This document is a process pointer, not a frozen claim that every dependency is legally approved.

Re-run the license audit for the exact packaged artifact before external distribution. Electron, Chromium, Node.js, native modules, and installer notices still require release-time review.
